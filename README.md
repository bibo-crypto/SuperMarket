# 🛒 NoorMarket — نظام إدارة سوبر ماركت

تطبيق سطح مكتب كامل لإدارة السوبر ماركت، مبني بـ Python و Tkinter، يغطي نقطة البيع، المخزون، الفواتير، العملاء، والتقارير — بواجهة عربية بالكامل.

## ✨ المميزات

- **نقطة بيع (POS):** شاشة بيع سريعة لإصدار الفواتير وحساب الإجمالي لحظياً.
- **إدارة المنتجات:** إضافة وتعديل المنتجات، الأسعار، والكميات في المخزون.
- **إدارة العملاء:** تسجيل بيانات العملاء وربطهم بالفواتير.
- **الفواتير:** إصدار فواتير PDF بدعم كامل للغة العربية (باستخدام `arabic-reshaper` و `python-bidi`).
- **رموز QR:** توليد QR code على الفواتير.
- **التقارير والإحصائيات:** تقرير يومي للمبيعات، أداء المنتجات، وحالة المخزون.
- **نظام صلاحيات:** حسابان منفصلان (مدير / كاشير) بكلمات مرور مشفّرة في قاعدة البيانات.
- **قاعدة بيانات محلية:** SQLite، تُنشأ تلقائياً عند أول تشغيل، بدون أي إعداد خارجي.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| Python | لغة البرمجة الأساسية |
| Tkinter / ttk | واجهة المستخدم |
| SQLite | قاعدة البيانات المحلية |
| ReportLab | توليد فواتير PDF |
| arabic-reshaper / python-bidi | دعم النص العربي في الـ PDF |
| qrcode | توليد رموز QR |
| Pillow | معالجة الصور والأيقونات |

## 🚀 التشغيل

```bash
git clone https://github.com/bibo-crypto/SuperMarket.git
cd SuperMarket
pip install -r requirements.txt
python main.py
```

### بيانات الدخول الافتراضية (للتجربة فقط)

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| مدير (Admin) | `admin` | `admin123` |
| كاشير (Cashier) | `cashier` | `cashier123` |

⚠️ **مهم:** غيّر كلمات المرور الافتراضية فوراً بعد أول تشغيل في أي بيئة إنتاج حقيقية، من شاشة الإعدادات داخل البرنامج.

## 📁 بنية المشروع

```
SuperMarket/
├── main.py            # نقطة تشغيل البرنامج
├── app.py             # نافذة تسجيل الدخول والتطبيق الرئيسي
├── database.py        # طبقة قاعدة البيانات (SQLite) وتشفير كلمات المرور
├── requirements.txt    # المتطلبات
└── ui/
    ├── pos.py          # شاشة نقطة البيع
    ├── products.py     # إدارة المنتجات
    ├── customers.py    # إدارة العملاء
    ├── invoices.py     # الفواتير
    ├── reports.py      # التقارير
    └── settings.py     # الإعدادات
```
